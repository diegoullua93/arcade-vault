### Detalle y evidencia (2026-11-13)

- **SEC-01.** `npm audit --json` en esta rama: `next` 16.0.0–16.4.0, crítico: GHSA-2464-fhr4-w9xw (RCE en Image Optimization con SVG), GHSA-673q-mjm6-r5xr (RCE en `use cache` que devuelve typed arrays); alto: GHSA-p3m5-59mp-jv5r (DoS en App Router con Server Actions). En el worktree `../arcade-vault-next-upgrade` (16.4.6) `npm audit` ya no lista `next`. Severidad propia Alta y no Crítica: la app usa Server Actions (el DoS aplica), pero no se demostró la condición de los RCE (no hay `next/image`, ni SVG en `public/`, ni `images.dangerouslyAllowSVG`; `getGames` devuelve objetos planos). Remediación: fusionar `chore/next-security-upgrade`, `npm run build` y repetir la auditoría.
- **SEC-07.** `curl` sobre el `next start` de este repo (puerto 3100): `/node_modules/next/package.json` y `/node_modules/@supabase/ssr/package.json` → 200 `application/json`. Expone versiones exactas (huella para SEC-01) y `.bin/`. No contiene `.env`, `.pem` ni `.key` (búsqueda hasta profundidad 3).
- **SEC-10.** `curl -I` en 3100 y 3101: sin las 3 cabeceras y `/login` → 404. El `.next/routes-manifest.json` actual (build de 2026-11-13 08:17) sí contiene las 3 cabeceras y la redirección `/login` → `/auth` (307): el servidor de 3100 arrancó el 2026-11-09 con un build anterior.
